# Programación de Asignaturas Structure

Route: `/alumnoWebSum/v2/matricula/programacion` (page title: “Sistema Único de Matrícula - Programación de Asignaturas”). The shared shell contains a page title, a “Descargar” control, and a long course-schedule table. Columns are a leading indicator, Asignatura, Créd., Sec., Docente, Tope, Matriculados, and Horarios. The table body contains many rows with a per-row action button; row contents were not saved.

No action button or download was activated because schedule details are account-specific and row actions may reveal student state.
