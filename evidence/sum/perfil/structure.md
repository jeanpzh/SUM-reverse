# Mi Perfil Structure

Route: `/alumnoWebSum/v2/informacion/perfil` (page title: “Sistema Único de Matrícula - Mi Perfil”). The shared student shell contains a main profile view with a summary panel, a “Descargar Perfil” action, and three tab controls: Información Personal, Información Académica, and Cambio de Contraseña. The initial state shows Información Personal. The account-specific heading and summary values are omitted. The password tab was not opened because it relates to account security.
