# Reporte de Pre-Matrícula — Structure

Route: `/alumnoWebSum/v2/reportes/prematricula` (page title: “Sistema Único de Matrícula - Reporte de Prematricula”). The main area contains a “Reporte de Prematricula” heading, one download action, and a table with columns Plan, Ciclo, Asignatura, Créditos, Nro. Rep, Nro. Mat. Equiv, Nro. Rep. Total, and Etapa. Personal academic row values were omitted.
