# Reporte de Horarios — Structure

Route: `/alumnoWebSum/v2/reportes/horarios` (page title: “Sistema Único de Matrícula - Horarios”). The page heading is “Reporte de Horarios de Asignaturas Matriculadas”. Below the shared shell and a student information panel, the content contains a weekly calendar widget. The panel’s personal and academic values are intentionally omitted.

The observed calendar is a static weekly grid with a day-name header and schedule area. No event values or student schedule details were retained.
