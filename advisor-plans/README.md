Generated by the improve skill on 2026-11-09 for the internal academic
planning product (`/local/programacion-academica`), revised the same day
after the operator restated that project conventions must not limit the
redesign. This directory is separate from `plans/`, which holds an unrelated
earlier analysis.

Each executor: read your plan fully before starting, honor its STOP
conditions, and update your row when done.

## Read this first: the working tree is not committed

The plans were written against commit `53f9251` **plus about 100 uncommitted
and untracked files** on branch `feat/planning-shadcn`. Several in-scope files
(`PlanningContextPanel.tsx`, `PlanningNormativeChat.tsx`, the chat and shimmer
components) exist only in the working tree.

- An executor started in a fresh git worktree from `HEAD` will not see that
  code and every plan will fail its drift check.
- Either commit the current tree first, or run the executors one at a time in
  this checkout. The plans assume the second option and forbid commits,
  stashes and resets.

## Decisions recorded

- **Conventions lifted** (operator, 2026-11-09): the redesign is not bound by
  the project's "no new dependencies", "keep existing ids, texts and
  structure" or "do not break existing scripts" conventions. Plans add
  `@radix-ui/react-tooltip` and `react-resizable-panels`, adopt the shadcn
  `sidebar`, `tooltip` and `resizable` registry components, replace the
  proposal-state select with a badge and explicit buttons, and remove the
  hidden theme select. Still binding: the `datos-reales/` prohibition, no
  change to student screens, and no change to API effects, validation, save
  semantics or academic rules.
- **Chat modes** (operator, 2026-11-09): keep a docked rail and a full-width
  mode; remove the draggable floating window and the collapsed state. Plan 001
  updates `docs/design-direction.md` accordingly.
- **Typeface and primary color**: the operator answered "lo recomendable".
  The recommendation taken is to keep the code as it is (Geist sans, blue
  primary). No plan changes typeface or palette. `docs/design-direction.md` was reconciled by the root with this accepted decision when resuming with Sol; typeface and palette were not changed.

## Open decisions for the operator

- **Font weight.** `.planning-root` uses `font-weight: 450`. The Geist family
  ships 400 and 500 only, so 450, 600 and 700 all render with the 500 file and
  bold text looks the same as body text. Setting the root to 400 would restore
  a visible Regular/Medium hierarchy. It was requested as 450 explicitly, so
  no plan changes it.

## Not audited

`AcademicResourceEditor.tsx` (1972 lines), `AcademicPreparationCourses.tsx`,
`AcademicTeacherReview.tsx` and `AcademicPublicationPanel.tsx` were not
reviewed in depth and are not redesigned by these plans. No browser session
was used, contrast was not measured, and the Playwright scripts were not
executed. The registry sources named in plans 001 and 002 were confirmed
reachable but their contents were not read while planning.

## Findings considered and rejected

- **Remove the guide (Tour) altogether**: rejected for now. Plan 003 repairs
  its targets; once the interface explains itself, removing it is a cheap
  follow-up.
- **Isolate planning CSS from the student stylesheets** (the global unlayered
  rules in `index.css` and `App.css` are why the kit needs "bridges" and has
  no preflight): deferred. It is the right structural fix but means a separate
  CSS entry point for the planning route, which is a build change of its own.
- **A spacing scale across all planning CSS**: deferred. Plan 004 is limited
  to font sizes to keep the diff reviewable.
